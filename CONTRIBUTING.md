# Guia de Contribuição


## Fluxo de trabalho


1. Crie uma branch a partir da 'main'

2. Faça sua alteração

3. Envie um Pull Request

4. Aguarde aprovação

5. Faça merge na 'main'


---


## Padrão de branchs

- feat/ ... -> novas funcionalidades

- fix/ ... -> correções

- docs/ ... -> documentação


## Exemplos

- feat/introducao-go

- fix/api-timeout

- docs/readme


---

## Regras

- Não fazer push direto na 'main'

- Todo código deve passar por Pull Request

- É necessário pelo menos 1 aproval

---

## commits

Exemplos:

- feat: adiciona introdução à linguagem Go

- fix: corrige erro de autenticação

- docs: atualiza README
